# Source / Firmware

This version uses an external digital timer relay module. Timing and relay behavior are configured directly on that module using its display and buttons.

There is no Arduino, ESP32, or other microcontroller firmware in the described implementation. No placeholder sketch is included because it would misrepresent the actual build.
